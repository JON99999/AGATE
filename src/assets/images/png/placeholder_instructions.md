# PNG Icon Source Placeholders

This directory contains tracked placeholder files for the source PNG icons. 

During AI Studio synchronization to GitHub, untracked/empty folders are missing from the environment and can get deleted or cause local files to be pruned. Having these placeholder files tracked under version control ensures the `src/assets/images/png/` folder structure is preserved in all environments.

Feel free to replace these placeholder files with your actual custom PNG icon sizes:
- `16x16.png`
- `24x24.png`
- `32x32.png`
- `48x48.png`
- `64x64.png`
- `128x128.png`
- `256x256.png`
- `512x512.png`
- `1024x1024.png`
- `icon.png`
