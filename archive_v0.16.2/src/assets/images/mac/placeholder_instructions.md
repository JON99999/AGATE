# macOS Icon Resource Placeholders

The `src/assets/images/mac/` folder contains your custom macOS icon files.

To customize the app icon for macOS, place your custom `.icns` file here:
- **Path**: `src/assets/images/mac/icon.icns`

Tracking this markdown file ensures the directory structure is preserved in Git/GitHub even if the actual custom `.icns` file is not checked in yet.
